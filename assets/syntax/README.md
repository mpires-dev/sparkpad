# Syntax queries

Bundled from the exact Tree-sitter grammar crates in Cargo.lock:
- C#: tree-sitter/tree-sitter-c-sharp 0.23.5 (MIT)
- Swift: alex-pinkus/tree-sitter-swift 0.7.4 (MIT)
- CMake: uyha/tree-sitter-cmake 0.7.5 (MIT); Lua predicates translated to Tree-sitter regex predicates.
- Protobuf: coder3101/tree-sitter-proto 0.2.0 (MIT)
- JSX: tree-sitter/tree-sitter-javascript 0.23.1 (MIT)

Licenses are included alongside the queries. GraphQL queries are authored for joowani/tree-sitter-graphql 0.1.0. Sparkpad combines C/C++ and JavaScript/TypeScript query inheritance and fills blank query configs in the older GPUI component registry before parsing. No online downloads occur at runtime.
